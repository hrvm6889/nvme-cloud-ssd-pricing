## NVMe 快在哪，以及云服务器上为什么会打折

NVMe 是 Non-Volatile Memory Express 的缩写，是给固态硬盘用的传输协议。它跟老一代 SATA/AHCI 的关键区别在队列：SATA 只有一条队列，深度 32 条命令；NVMe 走 PCIe 通道直连 CPU，队列数量最多 65535 条，每条队列还能排 65535 条命令。协议开销也从 AHCI 的寄存器轮询改成直接映射到内存，延迟更低。

对建站、编译、跑数据库的人来说，这个差别体现在随机读写，不是顺序读写。顺序读大文件，好一点的 SATA SSD 也能跑到 500MB/s 上下；真正拉开差距的是 4K 随机，数据库查一行、系统加载一堆小文件、容器启动，吃的全是这块性能。

云服务器上还会多一层变数：

- 物理机装一块企业级 NVMe，不等于你分到的虚拟盘就有独占性能。IOPS 可能被限制，也可能因为超售在晚高峰掉下来。
- 标着"NVMe"的机器可能在用 QLC 颗粒，持续写入一段时间后掉速，成本优势就是这么来的。
- 共享存储或软件定义存储会吃掉一部分性能，具体掉多少取决于厂商实现。

所以挑 NVMe 云服务器，商品页上的标签参考价值有限。能看的只有两样：实测数据，和这块盘能不能单独扩容。雨云广东深圳机房有第三方测评测过 4 核 4G 机型（Intel Xeon Platinum 8259CL），硬盘 I/O 读写约 947MB/s。这个数字只代表那个机房那个机型，但至少能说明它不是拿虚拟标签糊弄人的。

想知道自己手上的机器是不是真 NVMe，装个 fio 跑一轮随机读写最直接，别只看顺序读写的大数字。

## 几个常见问题

**流量叠加型的流量会清零吗？**
不会。套餐流量按 31 天一个周期补充，当月没用完的流量可以结转到下个月。但升级套餐时不补发当前周期内的差额，新套餐流量下个周期才生效。

**限速之后怎么办？**
流量耗尽后会进入限速状态，不同机房限速档位不一样（有 1Mbps 也有 5Mbps）。补上流量包就恢复正常带宽，雨云支持设置自动充值。
